# Тестовый проект для сортировки и отображения данных банковских карт

## Установка.
На этом этапе разработки установочного файла нет, поэтому  его можно только использовать в качестве функций облегчающих сортировку и отображение данных банковских карт.

## Использование. 
Для использования этих функций не нужны зависимости, нужно расположить файлы в директории проекта и призывать функции с помощью оператора input.

## Тестирование 
Проект прошел тестирование детальную  информацию можно найти в HTML.
